# Harmoni

Harmoni is a simple to-do app built with **Next.js**, designed for secure, project-based task management. It uses OTP and magic link authentication with a **KV store**, **PostgreSQL** for persistent data, and **[Streamthing](https://streamthing.dev)** for real-time updates.

---

## Features

-   ✅ **Project-based to-dos**  
    Users can create and manage tasks within a single project, keeping work organized and collaborative.

-   🔐 **OTP & Magic Link authentication**  
    Temporary tokens are stored in a **KV store** for secure, passwordless login.

-   🗄️ **PostgreSQL main database**  
    Stores users, projects, and tasks reliably.

-   🚀 **Real-time updates**  
    Powered by [Streamthing](https://streamthing.dev), ensuring tasks and changes are instantly visible to all project members.

-   ⚡ **Next.js-native architecture**  
    Built with **Server Actions** and **PPR (Partial Page Rendering)** for fast, reactive updates.
